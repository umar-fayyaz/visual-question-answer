# 👁️ Vision Q/A (LLM Fine-Tuned)

A modern, full-stack web application designed to run inference on a fine-tuned **Vision-Language Model (LLM)**. This project allows users to upload images and ask complex questions about them, receiving intelligent, context-aware answers generated by the custom fine-tuned model.

## 🌟 Features
- **State-of-the-Art VLM**: Powered by a multi-billion parameter Vision-Language Model.
- **Custom Fine-Tuning**: Utilizes LoRA adapters (via PEFT) trained specifically on Visual Question Answering (VQA) datasets.
- **Dynamic Glassmorphism UI**: A beautiful, responsive React frontend built with Vite and TypeScript.
- **Scalable Async Backend**: A robust FastAPI Python server using memory semaphores to strictly control GPU VRAM allocations.
- **Cloud-Ready**: Designed to easily connect to remote backend endpoints, allowing the heavy backend to run on free GPU cloud services (like Google Colab) while the frontend runs locally.

---

## 📁 Repository Structure

- `/frontend/` - The React (Vite) user interface.
- `/backend/` - The FastAPI Python server handling model inference.
- `/model/` - The fine-tuned LoRA adapter weights (`adapter_model.safetensors`), configuration, and updated processor files.

## 🚀 Getting Started

Because the Vision-Language Model requires a GPU with at least 8GB of VRAM to run effectively, the application is split into two parts: the lightweight Frontend (which runs on your laptop) and the heavy Backend (which can be hosted on a cloud GPU).

### 1. Run the Backend (Google Colab / Cloud GPU)
Upload this repository to a machine with a GPU (such as Google Colab). Run the following steps:

1. Install requirements:
   ```bash
   pip install -r backend/requirements.txt
   pip install nest-asyncio
   pip install -U "torchao>=0.16.0"
   ```
2. Start the FastAPI server (e.g., using a tunneling service or exposing the port).
3. Wait for the model to load into the GPU. Once started, you will have a public URL for your API.

### 2. Run the Frontend (Local Laptop)
1. Open the `/frontend/` directory on your local machine.
2. Install the necessary Node packages:
   ```bash
   npm install
   ```
3. Create a `.env` file inside the `frontend/` folder and paste your backend server URL:
   ```env
   VITE_API_BASE_URL=https://your-backend-url.com
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open your browser to `http://localhost:5173` and start analyzing images!
